Utiliser les données

QGIS

Menu Couche › Ajouter une couche › Ajouter une couche vecteur, choisissez le fichier .geojson téléchargé. Ou glissez-déposez-le dans QGIS.

Excel

Ouvrez le .csv : séparateur point-virgule, encodage UTF-8. La colonne geometrie_wkt contient la géométrie (importable dans QGIS comme « texte délimité »).
